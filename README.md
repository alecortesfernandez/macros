# Macros · contador de calorías

App web para apuntar comidas, escanear códigos de barras (con búsqueda en Open Food Facts), calcular calorías y macros según tu objetivo y planificar la semana con productos de Dia.

- Se abre en `https://alecortesfernandez.github.io/macros/` y se instala con "Añadir a pantalla de inicio".
- Los datos se guardan en el propio móvil (localStorage). Usa "Copiar copia" en la pestaña Objetivo para hacer copias.
- `prices.json` guarda los precios de Dia; se actualiza a diario.
